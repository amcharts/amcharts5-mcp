Packages and tutorials for using amCharts 5 with frameworks.

## Framework packages

For these frameworks there are packages that create and dispose the chart with your component. They load the library in the browser only, so they work with server rendering, and take a chart written in code or a chart from a [JSON config](https://www.amcharts.com/docs/v5/concepts/serializing/).

| Framework | Package | Tutorials |
| --- | --- | --- |
| React | [`@amcharts/amcharts5-react`](https://www.npmjs.com/package/@amcharts/amcharts5-react) | [React](https://www.amcharts.com/docs/v5/getting-started/integrations/react/), [Next.js](https://www.amcharts.com/docs/v5/getting-started/integrations/next-js/), [React Router](https://www.amcharts.com/docs/v5/getting-started/integrations/using-amcharts-5-with-remix/) |
| Vue | [`@amcharts/amcharts5-vue`](https://www.npmjs.com/package/@amcharts/amcharts5-vue) | [Vue.js](https://www.amcharts.com/docs/v5/getting-started/integrations/vue/), [Nuxt](https://www.amcharts.com/docs/v5/getting-started/integrations/nuxt/) |
| Angular | [`@amcharts/amcharts5-angular`](https://www.npmjs.com/package/@amcharts/amcharts5-angular) | [Angular](https://www.amcharts.com/docs/v5/getting-started/integrations/angular/) |
| Svelte | [`@amcharts/amcharts5-svelte`](https://www.npmjs.com/package/@amcharts/amcharts5-svelte) | [SvelteKit](https://www.amcharts.com/docs/v5/getting-started/integrations/using-amcharts-5-with-sveltekit/) |
| React Native | [`@amcharts/amcharts5-react-native`](https://www.npmjs.com/package/@amcharts/amcharts5-react-native) | [React Native](https://www.amcharts.com/docs/v5/getting-started/integrations/react-native/) |

Each package's README has the full API, and its [folder on GitHub](https://github.com/amcharts/amcharts5/tree/master/integrations) has example apps.

NOTE With a commercial license, call `am5.addLicense()` once when the app starts, before any chart is made. In React Native, use the `licenses` prop.
