## Properties

- **originalEvent** (`IPointerEvent`) — Original event object that caused the interaction, e.g. `MouseEvent`.
- **point** (`IPoint`) — The point of the event, relative to the root.
- **simulated** (`boolean`) — `true` if the event was generated by code rather than by user interaction.
- **native** (`boolean`) — Whether event originated in chart's container or its children.
- **cancelled** (`boolean`) — `true` on a `pointerup` or `globalpointerup` that ends a gesture without effect: the browser took it over (for example to scroll the page), or it was a swipe that `touchGestures` left to the page. _Since 5.23.0._
- **target** (`Sprite`) — The element on which the event occurred.
