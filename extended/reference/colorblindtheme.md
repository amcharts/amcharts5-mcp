"Colorblind": a series palette that stays distinguishable under the common forms of color blindness. It uses the eight Okabe-Ito colors, reordered so that black comes last, and repeats them rather than making new ones.

It sets only the series colors and leaves the interface colors alone.

Docs: https://jfly.uni-koeln.de/color/, https://www.amcharts.com/docs/v5/concepts/themes/

## Import

```js
import am5themes_Colorblind from "@amcharts/amcharts5/themes/Colorblind";

root.setThemes([am5themes_Colorblind.new(root)]);
```
