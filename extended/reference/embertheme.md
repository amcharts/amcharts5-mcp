"Ember": a warm dark theme on a near-black brown background, with series colors leaning to golds, oranges and reds, plus a few cool hues to tell series apart. It sets all interface colors, so use it instead of `Dark`.

Docs: https://www.amcharts.com/docs/v5/concepts/themes/

## Import

```js
import am5themes_Ember from "@amcharts/amcharts5/themes/Ember";

root.setThemes([am5themes_Ember.new(root)]);
```
